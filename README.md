# Список дел

Простенькое веб-приложение для списка дел на сегодня. Тестовое задание на стажировку.

**Тут приложение** https://alina170522.github.io/todo-list/

## Что умеет

По заданию:

- добавлять задачи (кнопкой или клавишей Enter);
- отмечать выполненные и снимать отметку;
- удалять задачи;
- сохранять задачи после обновления страницы.

Сверх задания:

- **«Вернуть» после удаления.** Задача не исчезает сразу: 5 секунд под ней видна подсказка с кнопкой «Вернуть»;
- **стикер-счётчик** «на сегодня N дел, сделано X/N», прикреплён скрепкой к краю карточки;
- **кнопка «наверх»** при длинном списке: возвращает к полю ввода и сразу ставит в него курсор;
- **календарь текущего месяца** открывается по нажатию на дату (только для просмотра);
- **цитаты** для пустого списка и для момента, когда всё выполнено;
- **адаптивная вёрстка** от 320 px до широких мониторов;
- если сайт открыт в двух вкладках, изменения из одной появляются в другой.

## Технологии

- Vue 3 (Composition API, `<script setup>`) и Vite;
- CSS без фреймворков, переменные для палитры;
- `localStorage` для хранения задач;
- шрифты Montserrat и Marck Script лежат в проекте (лицензия SIL OFL 1.1), иконки Tabler Icons (MIT) вставлены как SVG.

## Запуск

```bash
npm install
npm run dev      # локальный сервер для разработки
npm run build    # сборка в папку dist
npm run preview  # посмотреть собранную версию
```

## Публикация

Сайт публикуется на GitHub Pages автоматически: после каждого push в ветку `main` workflow `.github/workflows/deploy.yml` собирает проект и выкладывает папку `dist`.

## Структура

```
src/
  App.vue                  — страница: шапка, заголовок, стикер, форма, список
  components/
    AppHeader.vue          — дата и выпадающий календарь
    TaskSticker.vue        — стикер со счётчиком
    TaskForm.vue           — поле ввода и проверка пустой строки
    TaskItem.vue           — задача: отметка, удаление, «Вернуть»
    AppFooter.vue          — футер
    ScrollTopButton.vue    — кнопка «наверх»
    AppIcon.vue            — SVG-иконки
  composables/
    useTasks.js            — состояние списка, localStorage, удаление с отсрочкой
    useToday.js            — текущая дата, обновляется после полуночи
  utils/                   — даты, склонение «дело / дела / дел»
  styles/                  — шрифты и общие стили
tests/e2e.py               — проверка в браузере (Playwright)
```

## Решения и ограничения

- **Удаление в два шага.** Задача удаляется из `localStorage` только когда пройдут 5 секунд. Если обновить страницу во время отсчёта, задача вернётся.
- **Задачи хранятся только в этом браузере.** На другом устройстве или после очистки данных браузера их не будет. Об этом сказано в футере.
- **Текст задачи выводится как текст.** HTML в задаче не выполняется, строка `<img onerror=…>` просто отобразится.
- **Повреждённые данные в хранилище не ломают страницу.** Список откроется пустым, а мусорные записи будут отброшены.
- **У задач нет дат,** поэтому календарь только показывает месяц и сегодняшний день.
- На телефоне шрифт поля ввода 16 px, чтобы Safari на iPhone не приближал страницу при фокусе.

## Проверка

`tests/e2e.py` проходит 91 проверку в Chrome:

- пустой ввод и ввод из одних пробелов;
- добавление, склонение слова «дело»;
- отметка и сохранение после перезагрузки;
- удаление, «Вернуть», перезагрузка во время отсчёта, двойной клик по корзине;
- состояние «всё выполнено», календарь и Esc, синхронизация двух вкладок;
- XSS, повреждённые данные;
- кнопка «наверх»: появляется после прокрутки, возвращает к полю ввода, не появляется при коротком списке;
- на 320, 360, 375, 414, 768, 1280 и 1440 px: нет горизонтальной прокрутки, стикер со скрепкой стоит на краю карточки и не закрывает текст;
- доступность (axe) на 1280 и 375 px, в том числе с кнопкой «наверх»;
- отсутствие ошибок в консоли.

## Как бы я улучшила работу и что бы сделала дальше

Улучшить в текущей версии:

- **Контраст над фоном в точку.** Серый текст выполненных задач и фиолетовое «понедельник» на белом проходят норму, но там, где точка попадает под букву, контраст ниже 4,5:1. Можно чуть затемнить эти цвета.
- **Модульные тесты** логики списка (`useTasks`) на Vitest — в дополнение к проверкам в браузере.

Что сделать дальше:

- **Задачи по дням.** Выбор даты в календаре, у каждой задачи своя дата, дни с задачами отмечены. По сути это шаг от списка дел к простому планеру.
- **Редактирование задачи** без удаления и повторного ввода.
- **Фильтры** «все / активные / выполненные» и кнопка «очистить выполненные».
- **Порядок задач** перетаскиванием.
- **Синхронизация между устройствами.** Сейчас задачи живут только в одном браузере.
- **Напоминание в конце дня** о невыполненных задачах. Для настоящего уведомления, которое придёт при закрытой вкладке, нужны push-уведомления и сервер, а у сайта на GitHub Pages сервера нет. На iPhone веб-уведомления работают только у сайта, добавленного на экран «Домой».
